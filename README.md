# Shopping-List-Manager-Python-
A simple, beginner-friendly Shopping List Manager written in Python.
This project helps you practice working with lists, loops, functions, and user input.

🚀 Features

Add new items to the shopping list

Remove items from the list

View all items

Search for an item to see if it exists

Clear the entire list

Exit the program with a clean menu system

🎯 What You Will Learn

This project is great for practicing:

Python lists (adding, removing, searching)

Using loops to keep the program running

Working with functions to organize code

Validating user input

Building a simple text-based menu system
